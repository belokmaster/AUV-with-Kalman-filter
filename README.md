# Как запустить?
Ушли от логики на ГО, все переписано на питон, поэтому для запуска достаточно прописать в консоли одну команду:
```python main.py```


# Структура проекта:
main.py - бэкенд и ядро симуляции;<br>
static/index.html - содержит интерфейс и логику взаимодействия на стороне клиента;<br>

Проект запускается локально, после старта backend автоматически обслуживает frontend из папки static
